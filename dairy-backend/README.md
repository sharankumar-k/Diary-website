# PureDairy Backend

Express and MongoDB API for PureDairy contact enquiries.

## Setup

1. Copy `.env.example` to `.env`.
2. Set a real `MONGODB_URI` in `.env`.
3. Run `npm install`.
4. Start development with `npm run dev` or production with `npm start`.

## Endpoints

- `GET /api/health`
- `POST /api/contact`
- `GET /api/contact`
